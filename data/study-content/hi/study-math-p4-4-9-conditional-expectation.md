## 1. The one-sentence answer
**Conditional expectation** is the expected value of a random variable after you have already observed the value of another random variable that carries partial information about it.

Aap sochiye ki aap ek unbiased die ko roll kar rahe hain lekin kisi ne aapko sirf yeh bata diya ki outcome even hai. Ab aapka expected value 3.5 nahi rahega; woh badal jaayega kyunki aapne extra information use ki hai. Yeh adjustment hi conditional expectation hai — aap purane average ko nayi conditioning information ke hisaab se revise karte ho.

Mathematically yeh revision E[X | Y = y] ke through hota hai. Yahan X woh random variable hai jiska expectation aap nikaalna chahte ho aur Y woh information hai jo aapne observe ki hai. Poora function E[X | Y] ek random variable ban jaata hai kyunki yeh Y ke har possible value ke liye alag-alag number deta hai.

> [!NOTE]
> Sabse bada “aha” yeh hai ki conditional expectation khud ek random variable hai — yeh sirf ek number nahi, balki observed information ke hisaab se badalta rehta hai, aur iska apna expectation original E[X] ke barabar hota hai (law of total expectation).

## 2. Why this matters — concrete and current

## 3. Mental prerequisites

| Concept                    | Why you need it here                                      |
|----------------------------|-----------------------------------------------------------|
| Random variable            | Conditional expectation is itself a random variable built from other random variables. |
| Sigma-algebra / information | Conditioning is formally defined with respect to a sub-sigma-algebra generated by the observed variable. |
| Measure-theoretic integral | Expectation is an integral; conditional version is an integral with respect to a conditional measure. |
| Law of total expectation   | It is the fundamental consistency check that E[E[X|Y]] = E[X]. |

Agar aapko measure-theoretic probability abhi tak nahi aati, to pehle sigma-algebras aur Radon–Nikodym derivative padh lijiye.

## 4. Building the idea — from intuition to formalism

### Step 1 — Start with ordinary expectation
Aap already jaante ho ki E[X] = ∫ x dP ek single number deta hai. Ab sochiye ki aapne kuch information observe kar li hai; woh number ab change hona chahiye.

Example: fair die, E[X] = 3.5. Agar aapko pata chal jaaye ki X even hai, to naya number 4 hona chahiye.

Formal statement: E[X] = ∫_Ω X(ω) dP(ω).

> [!WARNING]
> Agar aap yahin soch lete ho ki “conditional expectation bhi ek fixed number hai”, to aage law of total expectation samajh nahi aayega.

### Step 2 — Partition the space according to observed information
Observed information ek partition banata hai sample space ka. Har block ke andar aap alag-alag average nikaalte ho.

Example: even-odd partition of {1,2,3,4,5,6}. Even block {2,4,6} ka average 4, odd block ka average 3.

Formal statement: Let 𝒜 be the sigma-algebra generated by Y. Then E[X|𝒜] is 𝒜-measurable and satisfies ∫_A E[X|𝒜] dP = ∫_A X dP for every A ∈ 𝒜.

> [!WARNING]
> Partition galat ban gayi (jaise overlapping events) to measurability condition toot jaayegi aur aapko function nahi random variable milega.

### Step 3 — Define conditional expectation as a random variable
E[X|Y] ek function hai jo har y ke liye E[X|Y=y] deta hai aur phir Y(ω) plug-in karke ek random variable ban jaata hai.

Example: E[X|Y even] = 4 jab Y even, = 3 jab Y odd. Iska matlab E[X|Y] naam ka random variable hai jo values 4 ya 3 hi le sakta hai.

Formal statement: E[X|Y] := g(Y) where g(y) = E[X | Y = y].

> [!WARNING]
> Students aksar g(Y) aur g(y) ko mix kar dete hain; yeh do alag cheezein hain — ek random variable, dusra number.

### Step 4 — Enforce the integral-matching property
Har measurable set A par integral barabar hona zaroori hai. Yeh property hi conditional expectation ko uniquely define karti hai.

Example: A = {even}, ∫_A E[X|Y] dP = 4·(1/2) = 2, aur ∫_A X dP = (2+4+6)/6 = 2, dono match karte hain.

Formal statement: E[X|Y] is the unique (a.s.) 𝒜-measurable random variable satisfying the above integral condition.

> [!WARNING]
> Agar yeh property verify nahi ki to uniqueness khatam ho jaati hai aur kai functions satisfy kar sakte hain.

### Step 5 — Recover the unconditional expectation
Law of total expectation kehta hai E[E[X|Y]] = E[X]. Yeh check karta hai ki information add karne se overall average nahi badalta.

Example: (1/2)·4 + (1/2)·3 = 3.5 = E[X].

Formal statement: ∫_Ω E[X|Y] dP = ∫_Ω X dP.

> [!WARNING]
> Yeh step bhool jaane se aap sochne lagte ho ki conditioning se expectation “badal” sakta hai — lekin woh sirf conditional distribution mein badalta hai.

### Step 6 — Move to general sigma-algebra (textbook level)
Ab 𝒜 kisi bhi sub-sigma-algebra ho sakti hai, na ki sirf Y se bani. Radon–Nikodym derivative se existence prove hoti hai.

Formal statement (Billingsley, *Probability and Measure*, 3e, §34): Let 𝒜 ⊂ ℱ. Then there exists a unique (a.s.) 𝒜-measurable integrable random variable Z such that ∫_A Z dP = ∫_A X dP ∀ A ∈ 𝒜; we write Z = E[X|𝒜].

## 5. Worked examples — har step show karo

**Example 1 — Simple discrete case**
*Given:* X uniform on {1,2,3,4}, Y = 1 if X even, 0 otherwise.
*Find:* E[X|Y].
Step 1: P(Y=1) = 1/2, E[X|Y=1] = (2+4)/2 = 3.  
*Why*: Conditioning set {2,4} ka ordinary average liya.  
Step 2: E[X|Y=0] = (1+3)/2 = 2.  
*Why*: Remaining outcomes ka average.  
Final answer:  
**E[X|Y] = 3·1_{Y=1} + 2·1_{Y=0}**

*Reflection*: Discrete case mein partition clear hoti hai, isliye calculation transparent rehti hai; yeh pattern continuous case mein bhi same rehta hai.

**Example 2 — Continuous uniform**
*Given:* (X,Y) joint uniform on [0,1]×[0,1].
*Find:* E[X|Y=y].
Step 1: f_{X|Y}(x|y) = 1 for x ∈ [0,1].  
*Why*: Independence ki wajah se conditional density marginal ke barabar hai.  
Step 2: ∫_0^1 x·1 dx = 1/2.  
*Why*: Ordinary integral of conditional density.  
Final answer:  
**E[X|Y] = 1/2 almost surely**

*Reflection*: Independence ne conditioning ko trivial bana diya; yeh check karta hai ki formula sahi jagah use ho rahi hai.

**Example 3 — Bivariate normal**
*Given:* (X,Y) ~ 𝒩((0,0), Σ) with Σ_{12}=ρ.
*Find:* E[X|Y=y].
Step 1: Joint density likho aur conditional density derive karo.  
*Why*: Standard completion-of-square technique.  
Step 2: Resulting normal mean ρ y.  
*Why*: Correlation coefficient directly slope deta hai.  
Final answer:  
**E[X|Y] = ρ Y**

*Reflection*: Linear regression ka probabilistic version yahin se aata hai.

**Example 4 — Indicator and filtration**
*Given:* Brownian motion W_t, filtration ℱ_s, t > s.
*Find:* E[W_t | ℱ_s].
Step 1: W_t = W_s + (W_t – W_s), increment independent.  
*Why*: Independent increment property.  
Step 2: E[W_t – W_s | ℱ_s] = 0.  
*Why*: Zero-mean martingale increment.  
Final answer:  
**E[W_t | ℱ_s] = W_s**

*Reflection*: Yeh martingale property ka seed example hai jo stochastic calculus mein kaam aata hai.

## 6. Common traps and how to avoid them

| Trap                              | Why it happens                              | How to avoid it                                      |
|-----------------------------------|---------------------------------------------|------------------------------------------------------|
| Treating E[X|Y] as a number       | Students forget it is still random          | Always write E[X|Y](ω) or g(Y(ω))                    |
| Confusing E[X|Y=y] with E[X|Y]    | Notation overlap                            | Use capital Y when the argument is random            |
| Forgetting to check measurability | Focus only on integral property             | Verify that answer is constant on atoms of 𝒜         |
| Using wrong sigma-algebra         | Thinking only of single Y                   | Explicitly write 𝒜 = σ(Y) before computing           |
| Ignoring null sets                | “Almost surely” feels optional              | State uniqueness holds P-almost surely               |
| Mixing conditional density with conditional expectation | Both use “|” symbol            | Remember density is f(x|y), expectation is ∫x f(x|y)dx |
| Assuming linearity without conditions | Expectation is always linear, but conditioning set must be same | Check that both variables are conditioned on identical sigma-algebra |

## 7. The textbook-precise statement
Let (Ω, ℱ, P) be a probability space, X an integrable random variable, and 𝒜 a sub-σ-algebra of ℱ. Then there exists a 𝒜-measurable integrable random variable Z such that  
∫_A Z dP = ∫_A X dP  
for every A ∈ 𝒜. Any two such versions coincide P-almost surely. We denote this Z by E[X | 𝒜]. When 𝒜 = σ(Y) for a random variable Y we write E[X | Y].  
(Billingsley, *Probability and Measure*, 3rd ed., Theorem 34.1)

## 8. Visual — diagram or schematic
```text
Ω
├── A1 (Y= y1) ──► E[X|Y=y1] = c1
├── A2 (Y= y2) ──► E[X|Y=y2] = c2
└── A3 (Y= y3) ──► E[X|Y=y3] = c3
```
Each Ai is an atom of σ(Y); inside Ai the conditional expectation is constant (the average of X over Ai).
